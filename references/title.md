# 标题生成（委托 bigpeng-hot-gzh）

为 AI 新闻日更 / X 文章推送生成公众号标题。标题统一调用已安装的 **bigpeng-hot-gzh** 技能生成，不自行套规律库。

## 输入约束（AI 新闻日更专用，必须保留）

**日报标题 = 当天最热门 / 最有代表性一条新闻的简写**，不概括全部条目。

1. **定主角**：从当天 3—5 条里选最热门的一条（score 最高或最吸睛/最接地气）。
2. 把这条的核心事实、关键数字、冲突点，作为 bigpeng-hot-gzh 的「文章描述」输入。

## 调用方式

1. 读 bigpeng-hot-gzh 技能（`~/.workbuddy/skills/bigpeng-hot-gzh/SKILL.md`），走**路径 A**。
2. 按 7 型公式出 6 个不同公式的候选标题 + 1 个首选。
3. 取它的「首选」作为 `--title`；若首选太宽泛、没点出具体事件，从其余候选中挑最贴合的。

## 兜底

bigpeng-hot-gzh 不可用（文件缺失/无法读取）时，回退下方内置规律库自行生成。

---

## （兜底）内置爆款标题规律库

| 规律 | 钩子 | 示例 |
|---|---|---|
| 数字 + 利益 | N 个 + 结果/好处 | 「3 个信号，说明 AI 编程正在变天」 |
| 痛点 / 悬念 | 提问式 / 反常识 | 「为什么你用的 AI 越来越贵」 |
| 情绪 / 冲突 | 制造对立与张力 | 「这次开源，真的动了闭源的蛋糕」 |
| 人群筛选 | 点名目标读者 | 「给每天要写公众号的人」 |
| 稀缺 / 时效 | 刚刚 / 最新 / 第一次 | 「刚刚发生，值得关注的一夜」 |
| 反差 / 转折 | 前半句铺垫、后半句反转 | 「AI 越强，反而越离不开人」 |

> 核心是「利益 + 好奇 + 具体」。

## 使用

- 推送前生成（供 `publish.cjs --title` 使用）。
- 最终标题 1 个，不做标题堆砌。
