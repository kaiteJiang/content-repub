# 关键词雷达（选题与内容优化前置）

**作用**：在抓新闻之前，先知道「本周 AI 圈哪些专业名词在被反复搜索/讨论」，据此定选题、写标题、铺正文关键词，提高文章被微信搜一搜收录的概率。

**重要前提**：微信「搜一搜」下拉词**没有可用的公开接口**（实测三路探测全部失败）。本环节用**竞品爆款标题里的高频 AI 专业名词**作为等效替代——它与下拉词的差别只是数据来源不同，用途完全一致：都是"被验证过有真实搜索/点击需求的词"。

## 一、生成词表

```bash
node scripts/seo-radar/seo_radar.cjs
```

> **路径约定（重要）**：脚本与两个配置文件（`seo_roots.json` / `seo_dictionary.json`）都在**本 skill 的 `scripts/seo-radar/` 目录**下，随 skill 一起分发，**与你的当前工作目录无关**。
> 最稳妥的写法是用 skill 目录的绝对路径：
>
> ```bash
> node "C:/Users/1/.workbuddy/skills/content-repub/scripts/seo-radar/seo_radar.cjs"
> ```
>
> 产出（`.workbuddy/seo/`）始终写到**你当前的项目根**：脚本会从当前目录向上探测含 `.workbuddy` 的目录；也可用 `--project E:/你的项目` 显式指定。

可选参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--weeks <n>` | 1 | 回溯周数（1 = 近 7 天） |
| `--max <n>` | 20 | 每个根词抓取条数 |
| `--project <dir>` | 自动探测 | 指定产出项目根（`.workbuddy/seo/` 的父目录） |
| `--json` | 关 | 只输出 JSON，不打日志 |

产出（均在**项目根**的 `.workbuddy/seo/`）：

| 文件 | 用途 |
|------|------|
| `keywords-YYYY-Www.json` | 本周词表，按 ISO 周归档（用于环比） |
| `latest.json` | 最新一次结果（下游直接读这个） |
| `radar-report.md` | 人读版报告，含升温词与新词 |

同周重复运行会**覆盖**当周文件；跨周运行会自动与上一周环比，产出「升温词」。

## 二、词表怎么用（读 `latest.json`）

关键字段：

- `terms[]`：本周高频专业名词，按出现次数降序。每项含 `term`、`count`、`samples[]`（样本标题）。
- `rising[]`：**升温词**（本周次数 > 上周），带 `delta`。做标题优先用这些。
- `fresh[]`：本周新出现，值得提前布局。
- `per_root[]`：各根词检索明细，含失败标记。

### 落到三处

1. **定选题方向**：`rising` + `fresh` 里的词，说明当下读者正在关注。优先围绕它们组稿。
2. **写标题**：调 bigpeng-hot-gzh 生成候选标题时，把 `rising` 的前 5 个词作为**必含关键词**候选交给它，让首选标题自然带上其中 1—2 个。
3. **铺正文**：正文里对 `terms` 前 15 的词，**首次出现时用完整专业写法**（如写「检索增强生成（RAG）」而非只写「RAG」），让微信搜索能命中长短两种写法。

## 三、与主管线的衔接

```
[新增] 关键词雷达 → 抓新闻 → 去 AI 味 → 排版 → 标题/封面 → 推草稿
```

- 雷达在**抓新闻之前**跑（约 3—5 分钟，取决于根词数与网络）。
- 若当天时间紧，可跳过雷达直接用上周词表（`latest.json` 仍在）。
- 雷达失败（搜狗反爬）时不阻塞主流程，照常出稿，但标题不含关键词优化。

## 五、已知限制（务必了解）

1. **搜狗反爬严格**：连续高频请求会返回 302。脚本已内置退避重试（3 次）+ 根词间隔（2.5—5 秒）+ 失败根词冷却 20 秒后补救。**不要连续多次跑**，一天跑一次即可。
2. **部分根词可能拿不到数据**：搜狗索引覆盖不全，实测「模型微调」长期返回 0 条，属正常。
3. **不是官方下拉词**：数据来自搜狗微信公开检索，仅用于选题参考，不代表微信官方搜索热度。
4. **依赖 cheerio**：本机 npm 在沙箱内会中断。若报找不到 cheerio，执行：
   ```bash
   cd C:/Users/1/.workbuddy/binaries/node/workspace
   npm install cheerio --registry=https://registry.npmmirror.com
   ```
5. **合规**：仅用于学习研究与个人选题参考，不高频调用、不做大规模商业爬取。
